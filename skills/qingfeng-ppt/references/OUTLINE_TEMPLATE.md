# PPT 大纲模板（qingfeng-ppt · 第 2 步产物）

> 这是一份**标准大纲文档**，由 AI 在读完文章/资料后，按「核心主题 → 4 部分 → 每部分 2+ 要点 → 每要点 2-6 条内容」的逻辑设计初稿。
> 你可以直接修改文字、调整顺序、增删页面，也可在 `# 页标题` 后加 `[版式]` 锁定版式。
> **改完、确认无误后，再让 AI 套模板生成 PPT。**

## 设计逻辑（先想清楚再写）

```
核心主题（一句话）
└─ 部分 1  [节标题]        ← 至少 4 个部分
   ├─ 要点 A  (# 一级标题)  ← 每个部分 ≥2 个要点，每要点一页
   │   ├─ 关键词 a  + 核心内容  ← 每个要点 2-6 条内容
   │   ├─ 关键词 b  + 核心内容
   │   └─ 关键词 c  + 核心内容
   └─ 要点 B  (# 一级标题)
       ├─ 关键词 a  + 核心内容
       └─ 关键词 b  + 核心内容
└─ 部分 2  [节标题]
   └─ …
```

- **一级标题 `#`** = 每页的要点（灌入**标题文本框**）
- **二级标题 `##`** = 该要点下的一个关键词（精炼小标题，灌入**关键词文本框**）
- **关键词下方的正文段** = 该关键词的核心内容（灌入对应的**添加文本文本框**，与关键词一一配对）

## 严格 md 格式（生成逻辑据此灌字，务必遵守）

| md 写法 | 含义 | 灌入的模板文本框 |
|---|---|---|
| `# 页标题` | 一级标题（每页一个，开始新页） | **标题文本框** |
| `## 关键词` | 二级标题（每页 2-6 个，紧跟核心内容） | **关键词文本框** |
| `## 关键词` 下方的段落 | 该关键词的核心内容 | **对应的「添加文本」框** |
| `# 页标题 [版式名]` | 锁定该页版式（可选） | — |

- 一个 `# 页标题` = 一页 PPT。
- **每个 `## 关键词` 后面必须紧跟它的核心内容**，二者一一配对；下一 `##` 开始新的关键词。
- 关键词不是单词，而是「精炼小标题」（2-8 字，能概括那句话），如"警惕为活动而活动""主题即锚点"。

## 怎么改

- **改文字**：直接编辑标题 / 关键词 / 核心内容。
- **定义版式**：在 `# 页标题` 行末尾加 `[版式名]`，如 `# 录取对比 [两栏]`。
  - 不写标注 → AI 按该页关键词数量自动选版式（见下表）。
  - 写了标注 → 严格按标注来（中文 / 英文 / 序号均可：`[两栏]`=`[2col]`=`[04]`）。
- **增删页**：直接增删 `# 页标题` 小节即可。
- **图片页**：标题后标 `[左图右文]` / `[大图]` / `[四图]` 等，生成后**图片占位符是空的**，请在 PowerPoint 里手动把图拖进去（技能只灌文字、绝不自动塞图）。
- 标注完整写法见 `大纲标注说明.md`。

## 自动选版式（无标注时，按关键词数量）

| 关键词(二级标题)数 | 自动选用 |
|---|---|
| 0（仅标题或标题+正文） | 单栏 / 图文版式 |
| 2 | 两栏 |
| 3 | 三栏 |
| 4 | 四栏 |
| 5-6 | 六栏 |
| 仅标题、无正文、无关键词 | 节标题 |
| 标注 `[封面]`/`[目录]`/`[空白]` | 对应特殊版式 |

> **丰富度提示**：一份好的 PPT 不要每页都提炼相同数量的关键词。模板支持 两栏(2) / 三栏(3) / 四栏(4) / 六栏(6)，请在 2-6 之间**按内容灵活取数、尽量覆盖 2、3、4、6 几种栏数**，让页面有疏密对比。模板无 5 栏版式，5 条内容会落六栏（留一空栏），应避免。

## 14 个版式一览（标注写法）

| 标注（中文） | 标注（英文） | 序号 | 适合内容 |
|---|---|---|---|
| `[封面]` | `[cover]` | `[00]` | 主标题 + 副标题（正文第一段作副标题） |
| `[目录]` | `[toc]` | `[01]` | 目录列表 |
| `[节标题]` | `[section]` | `[02]` | 章节分隔大标题（= 一个「部分」） |
| `[单栏]` | `[1col]` | `[03]` | 一段完整文字 |
| `[两栏]` | `[2col]` | `[04]` | 两个并列要点 |
| `[三栏]` | `[3col]` | `[05]` | 三个并列要点 |
| `[左图右文]` | `[img_left]` | `[06]` | 图在左、字在右 |
| `[右图左文]` | `[img_right]` | `[07]` | 字在左、图在右 |
| `[大图]` | `[full_img]` | `[08]` | 一张全屏图 |
| `[四图]` | `[4images]` | `[09]` | 4 张图 |
| `[三图]` | `[3images]` | `[10]` | 3 张图 |
| `[四栏]` | `[4col]` | `[12]` | 四个并列要点 |
| `[六栏]` | `[6col]` | `[13]` | 六个并列要点 |
| `[空白]` | `[blank]` | `[11]` | 自由排版（占位符全空，自己加） |

## 大纲示例（按新方法论设计，关键词数量 2/3/4/6 搭配，科教践新节选）

> 注意示例中**每页关键词数都不同**：有的 2 个（两栏）、有的 3 个（三栏）、有的 4 个（四栏）、有的 6 个（六栏），整份有疏有密。这正是一份丰富 PPT 该有的样子。

```markdown
# 巧做跨学科融合，打造有温度的科学校本课程 [封面]
XX 学校科学教研组 · 2026

# 目录 [目录]
一、整体架构思路
二、跨学科融合的具体路径
三、问题反思：融合的"形"与"神"
四、出路探讨：打造有温度的课程

# 一、科学校本课程的整体架构思路 [节标题]

# 理念先行：让科学教育有"魂" [两栏]
## 警惕"为活动而活动"
很多学校科技节、竞赛热热闹闹却缺逻辑主线，学生参与多却无体系。
## 理念是课程总纲
目标、内容、方式、评价都要围绕核心理念展开，不各行其是。

# 系统架构：让课程体系有"型" [四栏]
## 横向三层进阶
基础型普及常识、拓展型延伸兴趣、探究型深度研究，覆盖全体到拔尖。
## 纵向学段衔接
低中高年级分别侧重观察体验、探究应用、研究创造，避免重复劳动。
## 主题聚合内容
围绕生命/物质/地球/技术四大领域设计模块，散沙变树状体系。
## 评价闭环反馈
以表现性评价贯穿始终，用作品与过程数据反哺课程迭代。

# 二、跨学科融合的具体路径 [节标题]

# 科学+语文：让表达有文采 [三栏]
## 观察写作结合
写观察日记，用文学语言描述科学现象，表达与理解双向深化。
## 童话故事创作
把水循环等知识编成童话，在创作中内化科学原理。
## 科普阅读拓展
推荐优秀科普读物、读书分享，拓宽视野也提升阅读力。

# 科学+德育：在探究中成人 [六栏]
## 环保意识
饲养与种植中体会生命依存，萌发守护自然的自觉。
## 工匠精神
反复调试装置、记录数据，养成严谨踏实的研究态度。
## 合作探究
小组分工协作完成任务，学会倾听、妥协与共同决策。
## 珍爱生命
亲历生老病死，理解生命尊严，学会温柔对待周遭。
## 科学伦理
讨论克隆、AI 等议题，建立技术向善的价值判断。
## 家国情怀
用本土生态、家乡物产做课题，把小我连向大时代。

# 三、问题反思：融合的"形"与"神" [节标题]

# "拼盘式"融合：简单相加的尴尬 [两栏]
## 何为拼盘
多学科围绕同一主题各讲各的，看似融合实则两张皮。
## 走向有机
以共同问题为锚，各学科不同角度切入、相互支撑。

# 形神割裂：热闹背后的虚浮 [三栏]
## 重形轻神
只求活动好看，忽略科学思维与价值体认的内核。
## 学科本位
教师仍守着自己的一亩三分地，融合停在表层。
## 评价错位
用知识量衡量融合成效，看不到素养的真实生长。

# 四、出路探讨：打造有温度的课程 [节标题]

# 主题引领：寻找核心锚点 [四栏]
## 主题即锚点
好主题凝聚多学科内容，决定融合深度与效果。
## 选择原则
贴近学生生活、具足够包容性，能容纳多科视角。
## 系列设计
大小主题有逻辑关联，在持续探究中建立整体世界图景。
## 真实情境
从校园、社区、自然中取材，让学习连接真实问题。

# 实施保障：让课程落地生根 [六栏]
## 教师协同
组建跨科备课组，定期开展联合教研与课例研讨。
## 资源建设
开发校本学材、实验包与数字资源，沉淀可复用资产。
## 课时统筹
在综合实践、社团与学科中灵活嵌入，避免额外增负。
## 家校共育
把家庭实验、亲子观察纳入课程，放大育人半径。
## 评价激励
以成长档案、作品展评替代分数，看见每一个进步。
## 平台支撑
借力校外基地与高校实验室，把课堂延伸到更广阔天地。

# 结语 [单栏]
有温度的科学校本课程，是在学生心里种下热爱科学、热爱生活、热爱生命的种子。
```

> 上例为节选；完整大纲应覆盖全部 4 个部分、每部分 2-3 个要点，每个要点 2-6 条内容，且**关键词数量在 2/3/4/6 间有变化**。
> 写完后跑 `scripts/validate_outline.py` 校验结构是否达标（它还会在"所有内容页关键词数雷同"时给出丰富度提示）。

## 书写规则速记
1. 每页用 `# 页标题` 起头；要点下设 `## 关键词` + 紧随的核心内容（一一配对）。
2. 至少 4 个 `[节标题]` 部分；每个部分 ≥2 个要点页；每个要点页 2-6 条内容。
3. `[版式]` 标注放在 `# 页标题` 行末尾，一页只标一个；标注优先于自动匹配。
4. 正文页标题单行显示，建议不超过 15 个字；关键词是精炼小标题，不是单词。
5. 图片版式只填标题和文字，图片占位符留空待你手动添加。
6. **颜色、字号等样式由模板决定，生成阶段一律不改；生成后你在 PowerPoint 里自行调整。**
