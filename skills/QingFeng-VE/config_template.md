# 轻风视频剪辑 - 一键配置模板

**使用方式**：复制下方模板填写，一次性完成所有配置，无需多轮交互。

---

## 配置模板

```
【视频配置模板】

* 1. 项目名称：_______________
   └─ 用于成品命名（如：周岁快乐、教育成果汇报）

* 2. 配音文本来源：（A/B）
   ├─ A. 生成文本 — 请提供：主题、风格要求、目标时长（选A清空下一行）
   └─ B. 已有文本 — 请直接粘贴文本内容（选B清空上一行）
      （分段剪辑请在分段处加【1】【2】……）

3. 剪辑模式：（A/B）
   ├─ A. 一剪到底 — 所有素材放同一目录，整体混剪
   └─ B. 分段剪辑 — 按文本分段，每段对应独立素材文件夹
      注：B模式需在文本分段处添加【1】【2】【3】标记

4. 视频比例：（A/B/C/D）
   ├─ A. 16:9 横屏（电脑/电视观看）
   ├─ B. 9:16 竖屏（抖音/视频号/快手）
   ├─ C. 自定义比例（如 4:3、21:9）
   └─ D. 自动检测（根据素材比例自动决定）

* 5. 素材路径：_______________
   └─ 文件夹完整路径（如：D:/个人/资源/生活点滴/周岁）

6. 配音音色：_______________（可选，默认 zh-CN-YunyangNeural）
   可选音色：
   男声（5种）：
     zh-CN-YunxiNeural — 清新
     zh-CN-YunyangNeural — 大气播报（默认）
     zh-CN-YunxiaNeural — 活泼
     zh-CN-YunjianNeural — 坚实
     zh-CN-liaoning-XiaobeiNeural — 东北
   女声（3种）：
     zh-CN-XiaoxiaoNeural — 温柔
     zh-CN-XiaoyiNeural — 知性
     zh-CN-shaanxi-XiaoniNeural — 陕西

   如需克隆声音：请自行搭建本地模型（推荐 Qwen3-TTS），克隆音色文件路径：_______________

7. 背景音乐：（A/B/C）
   ├─ A. 自动生成 — 根据配音情绪自动生成配乐
   ├─ B. 指定音频 — 提供音频文件路径（.mp3/.wav）
   └─ C. 不加背景音乐

8. 片头设置：（A/B/C/D）
   ├─ A. 添加标题 — 提供标题文本（如：周岁快乐）
   ├─ B. 自定义图片 — 提供图片路径
   ├─ C. 自定义视频 — 提供片头视频文件路径
   └─ D. 不加片头

9. 片尾设置：（A/B/C）
   ├─ A. 添加感谢语 — 提供文字内容（如：幸福一家人）
   ├─ B. 自定义视频 — 提供片尾视频文件路径
   └─ C. 不加片尾

10. 输出目录：_______________（默认 output/）
```

## 完整示例

```
【视频配置模板】

* 1. 项目名称：周岁快乐
* 2. 配音文本来源：B
   文本内容：今天是个特别的日子，我们的小宝贝一周岁了。这一年，你从襁褓中的小婴儿，长成现在会跑会跳的小调皮。看着你一天天长大，我们心里充满了幸福和感动。
3. 剪辑模式：A
4. 视频比例：B
* 5. 素材路径：D:/个人/资源/生活点滴/周岁
6. 配音音色：zh-CN-YunyangNeural
7. 背景音乐：A
8. 片头设置：A
   标题：周岁快乐
9. 片尾设置：A
   文字：幸福一家人
10. 输出目录：D:/趣味活动/剪辑工具/output/
```

## 参数说明

| 参数 | 是否必需 | 默认值 | 说明 |
|------|---------|--------|------|
| *项目名称 | 是 | - | 用于成品文件命名 |
| *配音文本来源 | 是 | - | A生成 / B已有 |
| 剪辑模式 | 否 | A | A一剪到底 / B分段剪辑 |
| 视频比例 | 否 | 自动检测 | A16:9 / B9:16 / C自定义 / D自动 |
| *素材路径 | 是 | - | 视频素材文件夹 |
| 配音音色 | 否 | zh-CN-YunyangNeural | edge-tts 语音合成音色 |
| 背景音乐 | 否 | C不加 | A自动 / B指定 / C不加 |
| 片头设置 | 否 | D不加 | A标题 / B图片 / C视频 / D不加 |
| 片尾设置 | 否 | C不加 | A感谢语 / B视频 / C不加 |
| 输出目录 | 否 | output/ | 成片存放位置 |

---

## 输出规范

- **成品命名**：`<项目名称>_<比例>完整版.mp4`
- **示例**：`周岁快乐_竖屏完整版.mp4`
- **存放位置**：`<输出目录>/<成品文件名>`

---

## 注意事项

1. **必填项**：带 `*` 的项目必须填写（项目名称、配音文本来源、素材路径）
2. **选择式填写**：每项有多个选项时，"选谁留谁，清空其他"
3. **素材要求**：每个素材视频建议 10-60 秒，总时长控制在 3-10 分钟
4. **文本格式**：长句建议拆分，每句控制在 25-30 字以内
5. **比例适配**：片头片尾会自动按主视频比例生成
6. **音频混合**：BGM 自动降增益（默认 0.3），配音原声永不消除
7. **项目目录**：建议为本项目新建一个目录，把所有素材均放入该目录中，包括本配置文档
