# 教育热点文章生成器（多平台 · 多体裁版）

## 任务目标

- 全网搜索当下最热、且与教育相关或有教育意义的话题（教育、科技、职场、育儿、心理健康、社会民生均可），遴选一个主题；
- 调用「轻风写作（qingfeng-writing）」技能，按 **今日头条 / 微信公众号 / 小红书** 三平台特点各写一篇；
- 用 **agnes-image** 技能生成 3 张平台封面 + 3 张内容插图；
- 每个平台产出 **docx 纯文本版、docx 图片版、HTML 版** 三份文件；
- 打包并输出详细地址。

## 用户画像强制执行要求（强制）

> ⚠️ **每次执行本技能，必须严格遵循以下全部要求，不可省略或跳过。**

- 执行前加载 `MEMORY.md` 个人画像；唤醒口令：「加载我的专属人设，严格遵从个人画像与三类文风规范。」
- 所有文字以用户第一人称「轻风教育」视角写作，体现复合型气质（体制内严谨思辨 + 研究者洞察通透 + 文人温润内敛）。
- **称呼红线**：用户自称「轻风教育」，**禁止**用「宿松县教育局」代指。
- 写作禁忌红线（与轻风写作一致，详见附录 D）：禁口水化/网络化/浮夸化、禁 AI 机械三段式、禁条目式（1.2.3）、禁杜撰虚构臆断、禁地毯词、克制特殊标点。
- 图片水印必须尽量小，不遮挡主体、不影响正常观感。

## 默认工作空间与产物路径

- 默认工作空间：`d:\chenw\AgentSpace\WorkBuddy`（用户指定其他空间除外）。
- 产物统一落在 `{workspace}/down/education-hotspot-{slug}/` 下，目录结构见附录 C。
- `{slug}` 用主题英文/拼音短串或日期，例如 `school-ac-20260706`。

## 标准流程

> ⚠️ 以下步骤不可省略，每步完成后自检是否符合用户画像与平台规范。

### 步骤一　全网热点搜索（泛教育口径）

- 工具：`WebSearch`（多组关键词并行）+ `WebFetch`（抓取来源页核实事实）。
- 搜索口径：**凡与教育有关、或有教育意义的话题都可入选**，不限于学校内。包括：
  - 教育政策/改革/考试/招生/减负/课后服务
  - 科技（AI、智能体、短视频对青少年影响）
  - 职场（青年就业、考公考研、学历焦虑）
  - 育儿（亲子、心理健康、手机管理、隔代养育）
  - 社会民生中具教育启示的事件（如校园安全、教育公平、家校冲突）
- 关键词策略（一次并行多组，覆盖热度与多领域）：
  - `"今日教育热点 {今日日期}"`、`"教育 热搜 {今日日期}"`
  - `"教育新闻 最新"`、`"未成年人 心理健康 热点"`
  - `"AI 教育 争议"`、`"家长 育儿 热点"`、`"职场 年轻人 教育启示"`
- 每条候选记录：话题、来源链接、热度信号（热搜/转发量/评论数）、教育关联点、事实要点。
- 输出：候选话题清单（5–8 条），供步骤二加权。

### 步骤二　主题遴选（三维加权）

对每个候选按三维度打分（各 1–5 分），加权求和排序：

| 维度 | 权重 | 含义 |
|------|------|------|
| 热度 | 0.4 | 搜索指数、热搜位置、社媒讨论量 |
| 现实意义 | 0.35 | 对教育实践/家长/教师的启示价值 |
| 教育相关度 | 0.25 | 与教育的直接或间接关联强弱 |

- 输出：推荐主题 + 评分理由；若用户已指定主题则跳过本步。
- 选题须确保素材真实可查（政策有出处、数据可核、案例有据），拒绝捕风捉影。

### 步骤三　体裁判定与三平台写作

> 本步**必须调用 qingfeng-writing 技能**获取对应文体规范，再动笔。

1. **体裁判定（三选一）**
   - 【随笔】评论与反思（qingfeng 随笔规范）：适合争议性、情绪性话题。
   - 【论文】解读与研究（qingfeng 教学规范）：适合政策解读、数据分析、机理剖析。
   - 【小故事】有教育/哲理意义的小故事（轻风技能未含，按附录 B 规范创作）：强钩子开篇、场景化叙事、收束点题，适合共鸣型、价值观型话题。
   - 选择依据：① 看主题哪种体裁更贴合；② 看哪种更易成爆款。三平台**可不同体裁**。

2. **平台分配建议（爆款导向）**
   - 头条：随笔评论 / 小故事（强冲突、强情绪、快节奏）。
   - 公众号：论文解读 / 随笔（深度、结构、论证）。
   - 小红书：小故事 / 随笔（共鸣、第一人称、轻量要点）。
   - 平台特征与写法细则见附录 A。

3. **写作执行**
   - 每平台独立成稿，加载 qingfeng-writing 对应规范，严格去 AI 味（见附录 D、qingfeng 4.5）。
   - 每篇正文内用标记 `[[ILLU1]]` `[[ILLU2]]` `[[ILLU3]]` 指定 3 张插图插入位置（插图在正文中段、转折、收束处各一，帮助脚本定位）。标记独占一行。
   - 标题按平台调性拟定（见附录 A），但都需真实、不夸大、不标题党到失真。
   - 小红书版允许轻量要点与 emoji，但核心仍为叙事/观点驱动，不得退化为机械 1.2.3 清单（平衡轻风禁忌与平台调性）。

4. 三篇稿分别保存为 `toutiao/article.md`、`wechat/article.md`、`xiaohongshu/article.md`。

### 步骤四　配图（agnes-image 技能，禁止用原生生图）

- 调用 **agnes-image** 技能生成图片（文生图用模型 `agnes-image-2.1-flash`；图生图编辑才用 `2.0-flash`）。可复用其 `scripts/generate_image.py`。
- 生成 6 张，全部存到主题根目录：
  - **3 张封面**（平台风格，见附录 A）：`cover_toutiao.png`、`cover_wechat.png`、`cover_xiaohongshu.png`
  - **3 张插图**（内容核心场景，三平台共用）：`illu1.png`、`illu2.png`、`illu3.png`
- 提示词要点：紧扣文章核心，有教育元素；封面按平台视觉调性（头条冲突大字感、公众号质感留白、小红书清新模板感）；水印尽量小。
- 在对话中以 `![描述](路径)` 展示全部 6 张图供预览。

### 步骤五　产物生成（docx + HTML）

> 用本技能自带脚本 `scripts/generate_outputs.py` 把每篇 `article.md` 转成三份产物。

对每个平台文件夹运行（封面与插图路径指向主题根目录）：

```bash
python {skill_dir}/scripts/generate_outputs.py \
  --md   {workspace}/down/education-hotspot-{slug}/{平台}/article.md \
  --cover {workspace}/down/education-hotspot-{slug}/cover_{平台}.png \
  --illu {workspace}/down/education-hotspot-{slug}/illu1.png \
         {workspace}/down/education-hotspot-{slug}/illu2.png \
         {workspace}/down/education-hotspot-{slug}/illu3.png \
  --out  {workspace}/down/education-hotspot-{slug}/{平台}
```

脚本产出（详见附录 C）：
- `article.docx`：docx 纯文本版（无图，`[[ILLU*]]` 标记转为「（配图*）」占位）。
- `article-images.docx`：docx 图片版（封面图置顶 + 正文 + 插图插在 `[[ILLU*]]` 处）。
- `article.html`：HTML 版（封面图在正文前，3 张插图插在对应 `[[ILLU*]]` 处，含基础排版样式）。
- 依赖 `python-docx`；若未安装先 `pip install python-docx`。

### 步骤六　打包与输出详细地址（强制）

```bash
cd {workspace}/down
Compress-Archive -Path education-hotspot-{slug} -DestinationPath education-hotspot-{slug}.zip -Force
```

执行完成后，**必须**在结尾按以下格式输出全部路径：

```

- 压缩包：`{workspace}/down/education-hotspot-{slug}.zip`

- 公众号：{workspace}/down/education-hotspot-{slug}/wechat/（同上）
- 小红书：{workspace}/down/education-hotspot-{slug}/xiaohongshu/（同上）

- 插图：illu1.png / illu2.png / illu3.png

💡 可在文件资源管理器中直接打开以上路径查看完整内容。
```

## 附录 A　三平台特征与写法

| 维度 | 今日头条 | 微信公众号 | 小红书 |
|------|----------|------------|--------|
| 受众 | 广泛、下沉、资讯消费型 | 成熟中产、家长教师、深度阅读 | 年轻女性、学生、家长、职场新人 |
| 标题调性 | 强冲突/悬念/数字/反差，抓眼球但不失真 | 克制有信息量、引发共鸣或思考 | emoji + 口语 + 痛点/干货感 |
| 正文节奏 | 开篇直给爆点，段落短（3–5 行），情绪足，金句加粗 | 结构清晰、逻辑递进、可长（1500–2500 字）、允许小标题 | 短句多分段、emoji 点缀、第一人称、轻量要点 |
| 推荐体裁 | 随笔评论 / 小故事 | 论文解读 / 随笔 | 小故事 / 随笔 |
| 封面风格 | 信息密度高、大字标题叠图、冲突感强、暖色抓眼 | 质感、留白、文艺简约、贴合意境 | 精美清新、大字标题、统一模板感 |

> 小红书版可在文中用少量「·」要点与 emoji 增强可读性，但**不得退化为机械 1.2.3 条目**，核心仍以叙事/观点驱动，遵守轻风写作禁忌。

## 附录 B　小故事体裁规范（本技能扩展，轻风写作未含）

用于「有教育意义或哲理意义的小故事」版本，需同时满足轻风写作禁忌（附录 D）。

- **强钩子开篇**：第一句就要把人拽住（反常情境、悬念、具体画面），不说套话。
- **场景化叙事**：用具体的人、地、物、动作、感官细节展开，不空发议论。
- **冲突/转折**：故事要有张力（误判、反转、顿悟），避免平铺直叙。
- **收束点题**：结尾用情节或意象自然点出教育/人生道理，不说教、留余味；可用一句断言或开放问题收尾。
- **字数**：800–1500 字，依平台节奏调整。
- **真实底线**：故事可典型化、可基于真实观察艺术加工，但不得虚构政策、伪造数据、编造可指认的当事人丑闻。

## 附录 D　写作禁忌红线（与轻风写作一致）

- ✗ 口水化、网络化、浮夸化词汇
- ✗ AI 机械三段式（首先…其次…最后 / 一方面…另一方面）
- ✗ 条目式呈现（1. 2. 3. 或 - 第一点 - 第二点 - 第三点）
- ✗ 杜撰、虚构、臆断（素材真实、数据可查、案例有据）
- ✗ 地毯词：综上所述、值得注意的是、另外、此外、可见、由此可见
- ✗ 生硬特殊标点（省略号、破折号、问号感叹号连用）
- 去 AI 味细则以 qingfeng-writing 第 4.5 节为权威依据，生成后逐条自检。
