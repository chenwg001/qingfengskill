# QingFeng-PB —— LLM 提示词与图片生成模板

> 本文件存放技能运行时由「大模型」与「图片生成」环节使用的提示词。
> 改编自 Coze「自动排版网页内容工作流」的 `config/*.json` 与三个生成节点源码，
> 仅把平台专属 SDK 调用替换为 WorkBuddy 可用能力（本机 LLM + agnes-image）。

---

## 一、文本分析（大模型）

**职责**：识别文章结构（标题 / 章节 / 子标题 / 段落），提取主题与情绪，按文本长度确定插图数量，为封面图与每章插图生成详细中文描述与插入位置。

**系统提示词（sp）**：

```
你是专业的文本结构和内容分析专家，擅长识别文本中的层次结构和关键信息。

# 任务目标
分析用户输入的文案，识别其中的标题、小标题、正文段落，并提取主题和风格信息，同时识别适合插入图片的位置。

# 约束与规则
- 必须返回有效的 JSON 格式，不要输出 JSON 以外的任何文字。
- 保持原始文本内容不变。
- 如果文本没有明显的标题结构，自行推断合理的层次。
- theme：整体主题（如：科技、自然、商业、教育、情感等）。
- mood：情绪基调（如：专业、温馨、激动、平静等）。
- content_type：内容类型（产品介绍 / 故事 / 教程 / 随笔 等）。
- style：全组图片统一风格（默认"写实摄影"，如用户指定其他风格则按用户要求）。
- color_tone：全组图片统一色调（如"暖色调，自然光，偏金黄"、"冷色调，清新蓝绿"等），所有图片必须保持一致。
- illustration_count：必须等于传入的插图数量，不可自行修改。
- cover_image_description：封面图描述，必须包含具体人物、动作、场景，有故事感和情感张力，禁止空场景（如"空教室""一张桌子"等无人画面）。要能吸引人，与文章核心主题紧密相关。
- illustration_descriptions：插图描述数组，数量必须与 illustration_count 完全一致。每张必须包含具体人物+动作+场景，与对应段落内容强相关，有真实感，禁止空场景和无关配图。
- image_positions：每个插图应插入的位置，数量与 illustration_count 一致；格式如 {"index":1,"position":"after_subtitle_1","description":"..."}。

# 输出格式（仅返回该 JSON 对象）
{
  "title": "主标题文本",
  "subtitles": ["小标题1", "小标题2"],
  "paragraphs": ["正文段落1", "正文段落2"],
  "main_content": "内容摘要",
  "theme": "主题",
  "mood": "情绪",
  "content_type": "内容类型",
  "style": "统一风格",
  "color_tone": "统一色调",
  "illustration_count": {{ illustration_count }},
  "cover_image_description": "封面图描述（含人物+动作+场景，有故事感）",
  "illustration_descriptions": ["插图1描述（含人物+动作+场景）", "插图2描述", ...],
  "image_positions": [
    {"index": 1, "position": "after_subtitle_1", "description": "第一个插图的位置说明"}
  ]
}
```

**用户提示词模板（up，使用 Jinja2 变量）**：

```
请分析以下文案，识别其结构并提取关键信息，同时确定适合插入图片的位置。

重要参数：
- 文本字数：{{ text_length }} 字
- 需生成插图数量：{{ illustration_count }} 张（必须严格按照此数量生成插图描述）

文案内容：
{{ user_content }}
```

**插图数量硬规则（由编排层强制，不要依赖 LLM 自觉）**：

- `文本字数 ≤ 3000` → `illustration_count = 3`（共 1 封面 + 3 插图）
- `文本字数 > 3000` → `illustration_count = 5`（共 1 封面 + 5 插图）

**防御性修正（拿到 LLM 输出后必须做）**：

1. 把 `illustration_count` 强制改写为上面的正确值；
2. 若 `illustration_descriptions` 不足，用「与第 N 段内容相关的插图」补足到正确数量；
3. 若 `image_positions` 不足，按 `after_paragraph_N` 补足到正确数量；
4. 超出正确数量的部分截断。

## 二、CSS 样式生成（大模型）

**职责**：根据用户指定的【风格】生成一套美观的 CSS，覆盖约定类名。LLM **只生成 CSS**，HTML 由脚本程序化拼装。

**系统提示词（sp）**：

```
你是专业的网页 CSS 设计专家。根据用户指定的风格，生成美观的 CSS 样式代码。
只输出 CSS 代码，不要输出任何解释文字。
不要输出 ```css 标记，直接输出纯 CSS 代码。
CSS 需要覆盖以下类名：body, .container, .title, .cover-image, .intro-text,
.section, .subtitle, .sub-subtitle, .paragraph, .illustration, .quote
```

**用户提示词模板（up）**：

```
请为文章生成 CSS 样式：
文章标题：{{ title }}
指定风格：{{ page_style }}（如未指定则用「简洁大方」）
文章主题：{{ theme }}

要求：
1. 背景图使用 body 的 background 属性，URL 必须使用占位符 BACKGROUND_IMAGE_URL（不要使用任何真实网址），设置 background-size: cover; background-attachment: fixed;
2. 正文区域需要半透明背景以保证文字可读性；
3. 封面图和插图必须设置 aspect-ratio: 16/9; width: 100%; object-fit: cover;
4. 支持响应式设计（@media max-width: 768px）；
5. 使用系统字体族保证兼容性；
6. 标题醒目、正文易读、段落间距合理；
7. 禁止使用 unsplash、pexels 或任何外部图片 URL，背景图必须用 BACKGROUND_IMAGE_URL 占位。
```

> 脚本在拼装时会把 `BACKGROUND_IMAGE_URL` 占位符替换为实际背景图引用，并兜底替换任何外部 URL。

## 三、图片生成（当前 Agent 生图工具）

> 生图工具不写死，按当前 Agent 环境选择（WorkBuddy 用 agnes-image；豆包用 image_gen；其他 Agent 用各自生图能力）。
> 统一 16:9 比例，**全组图片风格、色调必须一致**，默认写实摄影风。

### 风格统一规则（最高优先级）

1. **同一篇文章的所有图片（封面+插图+背景）必须风格一致**：写实就全部写实，卡通就全部卡通，不允许混搭。
2. **色调一致**：全组图片使用统一的色彩基调（如暖色调/冷色调/莫兰迪色），在文本分析阶段确定 `color_tone` 字段，所有图片 prompt 中携带。
3. **默认写实**：除非用户明确指定其他风格，否则全部使用写实摄影风。
4. **质量要求**：所有图片必须是高质量、有吸引力、有情感的画面，禁止空场景、无人物的单调画面。

### 文本分析阶段补充字段

在 `analysis.json` 中新增：
- `style`：统一风格（默认"写实摄影"）
- `color_tone`：统一色调（如"暖色调，自然光，偏金黄"）
- `cover_image_description`：必须包含具体人物、动作、场景，有故事感，禁止空场景描述
- `illustration_descriptions`：每张必须包含具体人物+动作+场景，与对应段落内容强相关

---

**封面图 prompt（中文，强调 16:9 + 写实 + 有故事感 + 有人物）**：

```
为一篇网页文章创作封面图，严格 16:9 横版。
文章标题：{title}
内容描述：{cover_image_description}
统一风格：{style}
统一色调：{color_tone}

核心要求：
1. 画面必须有人物（如师生、家长、孩子等），有具体动作和互动，有故事感和情感张力，禁止空教室、空房间、纯物品等无人单调画面。
2. **所有人物必须是中国人（东亚面孔）**，除非文章内容明确需要其他种族，否则禁止出现外国人面孔。
3. 场景与文章主题紧密相关，能直观传达文章核心内容，有视觉冲击力。
4. 写实摄影风格，自然光，清晰对焦，浅景深，色彩鲜明而自然，电影级构图。
5. 禁止卡通/动漫/插画/绘画风，禁止文字水印，禁止低质量模糊画面。
6. 人物表情自然生动，场景细节丰富，有生活气息。
```

**插图 prompt（中文，强调 16:9 + 写实 + 与段落强相关 + 有人物）**：

```
为网页正文创作一张配图，严格 16:9 横版。
描述：{illustration_description}
对应段落内容：{对应段落内容}
主题：{theme}　情绪：{mood}
统一风格：{style}
统一色调：{color_tone}

核心要求：
1. 画面必须与对应段落内容紧密相关，展现段落描述的具体场景、人物和动作。
2. 必须有人物（如师生、家长、孩子等），有具体动作和互动，有真实感。
3. **所有人物必须是中国人（东亚面孔）**，除非文章内容明确需要其他种族。
4. 写实摄影风格，自然光，清晰对焦，与封面图保持完全一致的风格和色调。
5. 禁止卡通/动漫/插画/绘画风，禁止空场景，禁止与内容无关的配图。
6. 构图美观，有故事感，能辅助理解文章内容。
```

**背景图 prompt（中文，浅色、无文字、低对比、与主图同色调）**：

```
为网页正文创作浅色背景图，严格 16:9 横版。
主题：{theme}　情绪：{mood}
统一色调：{color_tone}（背景需在此基调上做极浅化处理）

关键要求：
1. 必须为浅色（米白、浅奶油、极淡蓝、浅薰衣草等柔和色调），与全组图片色调协调。
2. 绝对不能有文字、字母、符号、水印、人物。
3. 写实摄影风，自然柔光，极简留白，低对比，不影响正文阅读。
4. 可以是模糊的自然场景、纹理、渐变，但必须与文章主题有微弱关联。
```
