# QingFeng-Cover 多平台封面制作技能

> 从 QingFeng-PB 中独立出来的封面制作环节。基础封面图由 QingFeng-PB 生成（16:9），本技能负责叠加标题并输出多比例版本。

---

## 一、能力总览

输入：基础封面图（QingFeng-PB 生成的 `cover.jpg`）+ 标题文字
输出：5 张封面图
- `cover_titled_16x9.jpg` — 带标题的 16:9 原版
- `cover_4x3.jpg` — 4:3（头条/百家号横版封面）
- `cover_3x4.jpg` — 3:4（小红书竖版封面）
- `cover_235x1.jpg` — 2.35:1（公众号头条封面/B站横版）
- `cover_1x1.jpg` — 1:1（公众号次条/朋友圈/方形封面）

---

## 二、核心规则（务必遵守）

1. **先加标题，再改尺寸** — 标题叠加在原始 16:9 基础图上，然后对带标题的图进行比例变换
2. **改尺寸不裁剪不填充** — 直接拉伸修改宽高像素，图片内容完整保留（允许变形，但不丢失任何内容）
3. **标题样式** — 底部半透明黑底条 + 白色粗体字 + 文字阴影，保证在任何背景上都可读
4. **短边基准 1080px** — 所有输出图短边为 1080px，长边按比例计算

---

## 三、使用方法

当用户说「做封面」「生成多平台封面」「把这张图做成各平台封面」时：

1. 确认基础封面图路径（通常是 QingFeng-PB 产物目录下的 `cover.jpg`）
2. 确认标题文字（用户提供，或从文章标题提取）
3. 执行脚本：

```bash
python D:/chenw/AgentSpace/.agents/skills/QingFeng-Cover/scripts/make_cover.py \
  --base "<基础封面图路径>" \
  --title "<封面标题>" \
  --subtitle "<副标题，可选>" \
  --outdir "<输出目录，可选>"
```

4. 用 `present_files` 交付生成的封面图

---

## 四、脚本参数

| 参数 | 必填 | 说明 |
|------|------|------|
| `--base` | 是 | 基础封面图路径（QingFeng-PB 生成的 cover.jpg） |
| `--title` | 是 | 封面标题文字 |
| `--subtitle` | 否 | 副标题文字（显示在标题下方，字号较小） |
| `--outdir` | 否 | 输出目录，默认与基础图同目录 |

---

## 五、输出比例与平台对应

| 文件名 | 比例 | 尺寸 | 适用平台 |
|--------|------|------|---------|
| `cover_titled_16x9.jpg` | 16:9 | 原始尺寸 | 通用基础版 |
| `cover_4x3.jpg` | 4:3 | 1440×1080 | 头条号、百家号横版封面 |
| `cover_3x4.jpg` | 3:4 | 1080×1440 | 小红书竖版封面 |
| `cover_235x1.jpg` | 2.35:1 | 2538×1080 | 公众号头条封面、B站横版 |
| `cover_1x1.jpg` | 1:1 | 1080×1080 | 公众号次条、朋友圈、方形 |

## 六、技术实现

- **图片处理**：Pillow（PIL）
- **字体**：自动查找系统中文字体（微软雅黑粗体 → 微软雅黑 → 黑体 → 宋体）
- **模糊扩展**：原图放大覆盖目标画布 → 高斯模糊(radius=40) → 压暗 → 作为背景
- **前景缩放**：原图等比缩放到能放入目标画布的最大尺寸，居中放置
- **标题叠加**：底部半透明黑底条(alpha=140) + 白色粗体字 + 黑色阴影偏移

---

## 七、与 QingFeng-PB 的关系

- QingFeng-PB 负责：文章排版 + 生成基础封面图（16:9，纯图无标题或含书法字标题）
- QingFeng-Cover 负责：在基础图上叠加醒目标题 + 输出多平台比例
- 两者串联：QingFeng-PB 生成 cover.jpg → QingFeng-Cover 用 cover.jpg 生成多比例封面
