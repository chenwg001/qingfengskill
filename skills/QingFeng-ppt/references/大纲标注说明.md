# 大纲版式标注说明（QingFeng-ppt 技能配套）

## 零、严格 md 格式（最重要）

生成 PPT 时，脚本只认 md 的层级来灌字：

| md 写法 | 灌入的模板文本框 |
|---|---|
| `# 页标题`（一级标题，每页一个） | 标题文本框 |
| `## 关键词`（二级标题，每页可有多个） | 关键词文本框 |
| 普通段落（正文） | 添加文本的文本框 |

- 一个 `# 页标题` = 一页 PPT。
- 页面内用多个 `## 关键词` 表示并列要点，脚本据此决定用几栏版式。

## 一、标注写法

格式：`# 页标题 [版式名]`

版式名中文、英文、序号三种写法均可，对照如下：

| 标注（中文） | 标注（英文） | 标注（序号） | 对应版式 | 适合内容 |
|---|---|---|---|---|
| `[封面]` | `[cover]` | `[00]` | 00_Cover_封面 | 主标题+副标题（正文第一段作副标题） |
| `[目录]` | `[toc]` | `[01]` | 01_TOC_目录 | 目录列表 |
| `[节标题]` | `[section]` | `[02]` | 02_SectionHeader_节标题 | 章节分隔大标题 |
| `[单栏]` | `[1col]` | `[03]` | 03_单栏 | 一段完整文字 |
| `[两栏]` | `[2col]` | `[04]` | 04_两栏 | 两个并列要点 |
| `[三栏]` | `[3col]` | `[05]` | 05_三栏 | 三个并列要点 |
| `[左图右文]` | `[img_left]` | `[06]` | 06_左图右文 | 图在左、字在右 |
| `[右图左文]` | `[img_right]` | `[07]` | 07_右图左文 | 字在左、图在右 |
| `[大图]` | `[full_img]` | `[08]` | 08_大图 | 一张全屏图 |
| `[四图]` | `[4images]` | `[09]` | 09_四宫格 | 4张图 |
| `[三图]` | `[3images]` | `[10]` | 10_横向三图 | 3张图 |
| `[四栏]` | `[4col]` | `[12]` | 12_四栏 | 四个并列要点 |
| `[六栏]` | `[6col]` | `[13]` | 13_六栏 | 六个并列要点 |
| `[空白]` | `[blank]` | `[11]` | 11_空白 | 自由排版 |

## 二、大纲示例

```markdown
# 2026年全市招生工作汇报 [封面]
副标题：市教育局基教科 · 2026年7月

# 目录 [目录]
一、总体情况
二、数据分析
三、下步安排

# 第一部分 总体情况 [节标题]

# 总体情况概述 [单栏]
今年全市共报名 XXXX 人，较去年增长 X%。

# 普高与职高录取对比 [两栏]
## 普高
录取 XXXX 人，录取率 XX%。
## 职高
录取 XXXX 人，录取率 XX%。

# 三县录取率对比 [三栏]
## 宿松县
XX%
## 太湖县
XX%
## 望江县
XX%

# 现场工作掠影 [左图右文]
（图片占位符留空，生成后请在 PowerPoint 里手动加图）
各考点组织有序，家长满意度高。
```

## 三、书写规则

1. **标注位置**：放在 `# 页标题` 行末尾，一页只标一个。
2. **不标注 = 自动匹配**：AI 数这一页有几个二级标题(关键词)，自动选版式
   （0→单栏，1–2→两栏，3→三栏，4→四栏，≥5→六栏；仅标题无正文→节标题）。
3. **标注优先**：标了就严格按标注来，即使内容数量和版式不完全匹配（多余模块会被忽略并提示）。
4. **图片页**：标题后标 `[左图右文]`/`[大图]`/`[四图]`/`[三图]` 等即可；生成 PPT 时
   **只填标题和文字，图片占位符留空**，由你之后在 PowerPoint 里手动把图拖进去（技能不自动塞图，以免破坏版式）。
5. **标题精炼**：正文页标题单行显示，建议不超过 15 个字。
6. **颜色与字号由模板决定**：生成阶段一律不改样式；生成后你在 PowerPoint 里自行调整。

> 生产规则（第 3 步）：只灌文字、不自动插图片、不改任何样式。任何图片 / 其他占位符都原样留空，等你生成内容后自行补充。

## 四、使用方法

把写好标注的大纲（严格 md）直接发给 AI，说一句：
> 用 QingFeng-ppt 按这个大纲生成 PPT

即可得到严格套用「轻风模板_规范版」的成品 PPT。
