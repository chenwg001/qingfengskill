# 轻风视频剪辑 qingfeng-VE 技能

## 简介

轻风视频剪辑是一个确定性短视频生产线技能，可将"素材 + 文案/主题"转化为"画面按顺序、每段必出现、配音与字幕同步、转场丰富"的短视频。全程可复现、可审计。

## 核心特性

- **确定性剪辑**：非随机混剪，按预设规则生成
- **双模式支持**：A模式（一剪到底）和B模式（分段剪辑）
- **灵活配音**：支持在线 edge-tts 和本地 Qwen3-TTS 克隆
- **智能时长匹配**：自动反推素材时长，确保音画同步
- **丰富转场**：内置多种转场效果交替使用
- **完整包装**：支持片头、片尾、背景音乐自动生成和添加

## 依赖说明

**必需依赖**：
- FFmpeg：视频处理核心
- edge-tts：在线配音引擎
- Pillow：图片处理
- numpy：音频处理

**可选依赖**（本地声音克隆）：
- torch + transformers
- qwen_tts 推理库
- 需配置环境变量 `QWEN_TTS_MODEL_DIR` 和 `QWEN_TTS_PYTHON`

## 运行依赖检测

```bash
python scripts/check_deps.py
```

## 技术架构

### 工作流程

```
工作流一：配音文本生成 → script.txt + script.json
工作流二：混剪生成主视频 → make_video.py
工作流三：包装处理 → BGM + 片头片尾
工作流四：最终交付 → output/
```

### 核心脚本

| 脚本 | 功能 |
|------|------|
| `make_video.py` | 主剪辑逻辑，支持A/B模式 |
| `tts.py` | TTS配音，支持edge和本地克隆 |
| `gen_bgm.py` | 自动生成背景音乐 |
| `video_factory.py` | 视频工厂工具 |
| `check_deps.py` | 依赖检测 |

### 配置说明

配置文件 `config.json` 用于本地 TTS 克隆环境配置：

```json
{
  "model_dir": null,
  "python_exe": null
}
```

可通过环境变量覆盖：
- `QWEN_TTS_MODEL_DIR`：模型目录
- `QWEN_TTS_PYTHON`：Python 解释器路径

## 使用示例

### 示例 1：基础剪辑

```
项目名称：团队活动记录
配音文本来源：B，文本内容如下：
  【1】今天是团队活动日。
  【2】我们一起完成了各种游戏。

剪辑模式：A
视频比例：16:9
素材路径：./materials/active/
配音音色：zh-CN-YunxiNeural
背景音乐：C
片头设置：D
片尾设置：A，感谢语：感谢观看
输出目录：./output/
```

### 示例 2：分步剪辑

```
项目名称：产品发布会
配音文本来源：A，主题：产品发布会回顾，时长：60秒
剪辑模式：B
视频比例：自动检测
素材路径：./materials/releases/
配音音色：zh-CN-YunyangNeural
背景音乐：C
片头设置：A，标题：产品发布会精彩回顾
片尾设置：A，感谢语：敬请期待更多精彩
输出目录：./output/
```

## 注意事项

1. 建议为本项目新建一个目录，把所有素材均放入该目录中
2. 素材建议按数字编号（如 `1.mp4`, `2.mp4`），便于排序
3. B模式分段时在文本中用 `【1】` `【2】` 等标记分段点
4. 配音时长默认 4.0-4.5 字/秒，可根据需要调整
