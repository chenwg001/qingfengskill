# 提示词模板（prompt-templates）

供 ImageGen（出分镜首帧/尾帧）与 VideoGen（动态镜头）使用。

> **使用顺序**：先做「第 0 步：诗意推敲」→ 再按 `poem.json` 的 `style` 选画风 → 最后填入对应模板生成首帧+尾帧 → VideoGen 做动作插值。

## 画风映射（style → ImageGen.style / 前缀）
| style | 含义 | ImageGen.style 词 | 适用诗境 |
|-------|------|-------------------|----------|
| `ink` | 水墨写意 | `水墨画` / `中国水墨` | 清冷、孤寂、空灵（多数唐诗） |
| `gongbi` | 工笔重彩 | `工笔画` | 细腻、富丽、春日繁花；**推荐用于需要建筑/人物比例准确的场景** |
| `realistic` | 写实实景 | `写实摄影` / `电影感写实` | 雄关、瀑布、大江等磅礴实景 |
| `guofeng` | 动画国风 | `国风动画` / `中国风插画` | 欢快、明媚、童话感（如早发白帝城、晓出净慈寺） |

> **通用前缀**（所有画风共用，置于 prompt 开头，根据精度需求调整）：
> - 精细版（推荐）：`中国传统美学，电影级构图，精细工笔国风插画，写实光影与质感。`
> - 写意版：`中国传统美学，电影级构图，细腻笔触，留白与意境，`
>
> 然后接 `{画风词}，` + 具体场景描述。

## 第 0 步：诗意推敲（⚠️ 必须先完成此步才能写提示词）

在调用 ImageGen 之前，对每首诗必须完成以下分析：

### 0.1 创作背景
- 谁？何时？何地？什么心境？
- 例：静夜思 = 李白，唐开元十四年（726年）秋，扬州旅舍，26岁离乡漫游，深秋夜独处，思乡情起

### 0.2 逐句画面转译（每句拆成：场景 + 人物姿态 + 动作）
| 句 | 字面含义 | 场景元素 | 人物起始姿态 |
|---|---------|---------|------------|
| 床前明月光 | 卧房内月光照到床前地面 | 古代卧房 interior：木榻、小格窗、矮案孤灯、帘幕；月光从窗斜射入照地 | 半卧榻上刚醒/坐起，目光落向地面 |
| 疑是地上霜 | 恍惚把月光误认为秋霜 | 同上房，地面月光如霜泛寒光 | 低头凝视地面，神情疑惑 |
| 举头望明月 | 抬头仰望天边明月 | 同上房，窗外明月高悬 | 头部低垂→抬起（**核心动作**）|
| 低头思故乡 | 低下头思念故乡 | 同上房，远处故乡山影虚现 | 从仰望转为垂目沉思 |

### 0.3 动作设计（每镜的首帧→尾帧差异）
- 封面镜：诗人侧坐→微微前倾（月更亮、帘动）
- 床前明月光：半卧→**坐起**（光斑扩大）
- 疑是地上霜：低头看地→**前倾伸手**（疑霜）
- 举头望明月：**低头→抬头望月**（全诗最关键动作！）
- 低头思故乡：仰望→**低头沉思**（故乡山影浮现）

> ⚠️ 如果某句诗没有明显的动作变化（如纯景物描写），则设计景物位移/光影流动作为首尾差异（如月光移动、云影飘过、花瓣飘落）。**绝对不能首尾帧完全相同。**

## 一、分镜提示词（给 ImageGen：首帧 + 尾帧）

> **⚠️ 构图方向随 `orientation` 变化**：所有模板末尾的「画面比例」一句必须按 `script.json.orientation` 替换——
> - `portrait`（默认）：写 `9:16 竖构图`（人物/景物以竖向高构图为主，如站立人物、高窗、立轴式留白）
> - `landscape`：写 `16:9 横构图`（电影感宽幅，人物可中近景偏侧、纳入更多横向环境——远山、江面、长廊、地平线等横向延展元素）
> 构图比例必须和首帧 `size`、成片 `--orientation` 三者一致，否则画面被裁切/黑边。

### 1.1 首帧提示词（动作起点）

封面镜：
```
{通用前缀}{画风词}，{scene_desc 意象的完整场景描述}。
具体包含：环境（建筑/室内/室外）、人物（姿态/衣着/位置）、道具（家具/器物）、
光线（光源/方向/色调）、氛围（情绪/温度感）。
建筑与道具比例准确（如「比例真实的小格木窗，非落地大窗」），
人物姿态自然，无文字无标语，9:16 竖构图（横屏时改为 16:9 横构图），电影感，极致精细笔触。
```

逐句镜（把第 0 步的分析结果填入）：
```
{通用前缀}{画风词}，同一{统一场景设定} interior：
人物{起始姿态}，{场景核心元素描述}。
{光线描述}，{氛围描述}，色调{色温描述}。
建筑与家具比例准确，人物姿态自然，无文字无标语，9:16 竖构图（横屏时改为 16:9 横构图），电影感，极致精细笔触。
```

### 1.2 尾帧提示词（动作终点——图生图）

以首帧为 `image` 参考（`input_fidelity: "0.82"`），描述同一场景的动作终点。

> **⚠️ 机位锁死（避免旋转假动）**：尾帧 prompt 必须强调「机位、镜头角度、构图与首帧**完全一致**，不得有任何视角/距离变化」。`input_fidelity` 提到 `0.82` 正是为了锁死背景——若 fidelity 过低（如 0.65），尾帧机位会漂移，VideoGen 就会把机位差当成「旋转」补出来，这正是上一版「全是旋转」的根源。
```
同一场景的后续瞬间（机位、镜头角度、构图与首帧完全相同，严禁任何视角/距离变化）：
人物从{起始姿态}变为{终止姿态}，{景物变化/光影变化/新出现的元素}。
同一{统一场景设定} interior，仅人物姿态与局部光影改变，画面构图不变，
无文字无标语。
```

> **关键原则**：尾帧 prompt 必须明确写出人物的**终态姿态**和景物的**变化量**，
> 让 ImageGen 在保持背景一致的前提下产出有足够差异的第二帧。

## 二、动态镜头提示词（给 VideoGen：配合 image + last_image）

> **⚠️ 铁律三：动态镜头必须「固定机位、画面内运动」，禁止任何镜头旋转/推拉/摇移。**
> 上一版成片「全是不同角度的旋转」就是因为 prompt 里写了「镜头推近/横移/上摇/拉开」这类运镜词，诱导模型用相机运动填补首尾帧。
> 正确的动态应来自：**人物在固定画面内完成动作 + 物体自然运动 + 光影渐变**，由首尾帧的姿态差驱动。

### 2.0 合理动态设计原则（生成脚本时必须先规划）
每个镜头的动态要符合该场景的**物理逻辑**，并服务于诗意，不是为动而动。按三层设计：

1. **人物动作层**（核心）：同一机位内的人物姿态变化。要有明确的起点→终点（如低头→抬头、坐→起、伸手→收回）。这是 VideoGen 首尾帧插值能产生「真动作」的根本。
2. **物体运动层**（辅）：符合物理的自然微动——烛火摇曳、帘幕被夜风轻摆、月影在地面缓缓游移、云影极缓飘过、落叶/花瓣飘落、水面波纹、衣袂微动。这些让画面"活"而不喧宾夺主。
3. **光影层**（衬）：随时间/情境的光影渐变——月光渐亮、烛光明灭、晨光浸染、阴影拉长。

> ❌ 禁止：镜头旋转、环绕、推近、拉远、横移、上摇、下摇、视角切换。
> ✅ 提倡：相机钉死，让"人动、物动、光动"。

### 2.1 VideoGen 动态 prompt 模板
```
{画风词}镜头，固定机位无镜头运动：
人物{完整动作过程，如「头部从低垂缓缓抬起、仰脸望向窗外明月」}；
{物体自然运动，如「帘幕被夜风轻轻拂动、烛火微微摇曳」}；
{光影渐变，如「月光在面庞上随抬头渐亮」}。
5秒，画面内运动自然流畅，无突兀剪辑，无镜头旋转。
```

常用"画面内动态"描述（按诗境选，须与首尾帧设计一致）：
- 思乡/清冷类：`诗人从{A姿态}缓缓变为{B姿态}；帘幕轻拂、烛火摇曳；窗外明月清辉微动`
- 行舟/旅途类：`诗人静立船头衣袂微动；江水缓流、远岸树木缓缓后退；天光渐变`
- 春日/生机类：`人物伸手轻触枝头；花瓣随风缓缓飘落、新叶微颤；晨光浸染`
- 登高/望远类：`诗人驻足远眺、衣袍被山风轻扬；云海在脚下极缓流动；夕照渐沉`
- 悲壮/苍凉类：`人物独立风中、披风微摆；荒草伏仰、远空雁阵缓移；暮色四合`

## 四、完整范例：静夜思（李白·唐）

以下展示从诗意分析到 10 张图 prompt 的完整流程，供后续所有诗参考。

### 4.1 诗意推敲结论
- **背景**：726年秋扬州旅舍，26岁李白离乡漫游，深夜独处，思乡
- **统一场景**：唐代旅舍卧房 interior（木榻 + 小格窗 + 矮案孤灯 + 半垂帘幕 + 青砖地面）
- **画风**：`工笔画`（精细写实，需准确建筑比例）
- **色调**：青蓝月白 + 孤灯暖黄对比

### 4.2 五镜首/尾帧 Prompt

> 以下为**竖屏 9:16 范例**（静夜思默认 portrait）。若本项目为横屏 `landscape`，请把每条 prompt 末尾的「9:16 竖构图」改为「16:9 横构图」，并相应放宽横向取景。

#### 镜 1 — 封面（游子异乡月夜）
- **首帧**：`中国传统美学，电影级构图，精细工笔国风插画，写实光影。唐代旅舍月夜，诗人独坐窗前榻上，侧身望向窗外一轮明月。室内：古朴木榻、小格窗、矮案孤灯、半垂帘幕。窗外可见夜空明月与远山剪影。清冷孤寂氛围，色调青蓝月白，月光洒入室内。人物中景侧影，建筑比例准确，无文字无标语，9:16 竖构图，电影感，极致精细笔触。`
- **尾帧**（img-to-img, fid=0.82，机位锁死）：`同一场景的后续瞬间：诗人身体微微前倾向窗，月光更亮地洒入室内，帘幕被微风轻轻拂动，窗外明月更皎洁清晰。构图与首帧保持一致，人物姿态有细微前倾变化，建筑陈设不变，无文字无标语。`
- **VideoGen 动作**：`精细工笔国风镜头，固定机位无镜头运动：诗人坐在榻上微微前倾望向窗外；帘幕被夜风轻轻拂动、案上孤灯烛火微微摇曳；窗外明月清辉微动、月光缓缓洒入室内更显明亮。5秒，画面内运动自然流畅，无镜头旋转。`

#### 镜 2 — 床前明月光
- **首帧**：`中国传统美学，电影级构图，精细工笔国风插画，写实光影与质感。唐代旅舍卧房 interior：一张古朴原木榻，诗人（古代文人，素色长袍）半卧榻上、刚从睡中醒来、目光落向榻前。一扇比例真实的小巧木格窗位于墙面，月光自窗外斜射入，在榻前青砖地面投下一片清辉光斑。室内简朴：矮木案、一盏孤灯、半垂帘幕。清秋月夜，孤寂思乡，色调青蓝月白。建筑与家具比例准确，人物姿态自然，无文字无标语，9:16 竖构图，电影感，极致精细笔触。`
- **尾帧**（img-to-img, fid=0.82，机位锁死）：`同一场景的后续瞬间：诗人从半卧坐起，上身挺直，目光仍落在榻前地面——月光光斑已扩大铺满更多地面，更明亮。同一唐代旅舍卧房 interior，构图与首帧基本一致但人物姿态变为坐起，无文字无标语。`
- **VideoGen 动作**：`精细工笔国风镜头，固定机位无镜头运动：诗人从半卧榻上缓缓坐起、上身挺直，目光落在榻前地面；地面月光光斑在青砖上缓缓扩大铺展变亮；烛火微摇。5秒，画面内运动自然流畅，无镜头旋转。`

#### 镜 3 — 疑是地上霜
- **首帧**：`中国传统美学，电影级构图，精细工笔国风插画，写实光影。同一唐代旅舍卧房 interior：诗人坐在榻边，低头凝视地面——地面上月光如霜般洁白泛着微寒的光泽。小格窗外月色清冷，室内孤灯微明。诗人神情带着一丝疑惑（疑是霜？），身体微微前倾俯视地面。青砖地面反着冷白月光，如铺了一层薄霜。清冷月夜，孤寂，色调偏冷蓝白。建筑比例准确，人物姿态自然，无文字无标语，9:16 竖构图，电影感，极致精细笔触。`
- **尾帧**（img-to-img, fid=0.82，机位锁死）：`同一场景的后续瞬间：诗人身体更前倾，一只手伸出、指尖几乎触到地面的月光（疑是霜），神情更加疑惑专注。月光如霜的地面特写感更强。同一卧房 interior，构图一致，无文字无标语。`
- **VideoGen 动作**：`精细工笔国风镜头，固定机位无镜头运动：诗人身体缓缓前倾、一只手伸出指尖几乎触到地面月光（疑是霜），俯身更近凝视、神情疑惑专注；地面月光如霜微微泛动；烛火轻摇。5秒，画面内运动自然流畅，无镜头旋转。`

#### 镜 4 — 举头望明月（⭐ 核心动作镜）
- **首帧**：`中国传统美学，电影级构图，精细工笔国风插画，写实光影。同一唐代旅舍卧房 interior：诗人坐在榻上，头部低垂、目光落在地面（承接上一句疑是地上霜的低头姿态）。小格窗外可见一轮明月高悬夜空。室内孤灯、帘幕、木榻同前。诗人即将抬头的瞬间——颈部有抬头趋势但头仍低着。清冷月夜，色调青蓝，建筑比例准确，人物姿态自然，无文字无标语，9:16 竖构图，电影感，极致精细笔触。`
- **尾帧**（img-to-img, fid=0.82，机位锁死）：`同一场景的后续瞬间：诗人头部已完全抬起，仰脸望向小格窗外高悬的明月，颈部线条显示抬头完成姿态，月光映在脸上。同一卧房 interior，构图与首帧一致，无文字无标语。`
- **VideoGen 动作**：`精细工笔国风镜头，固定机位无镜头运动：诗人头部从低垂缓缓抬起、颈部完成抬头动作、仰脸望向窗外高悬的明月、月光映上面庞；这是全诗最关键的动作——举头望月；帘幕轻拂。5秒，画面内运动自然流畅，无镜头旋转。`

#### 镜 5 — 低头思故乡
- **首帧**：`中国传统美学，电影级构图，精细工笔国风插画，写实光影。同一唐代旅舍卧房 interior：诗人坐在榻上，仰头望着窗外明月（承接上一句举头望明月的姿态）。面部表情从仰望转为若有所思的惆怅。小格窗外明月皎洁，远处隐约可见淡墨般的远山轮廓（故乡意象）。室内孤灯、帘幕、木榻同前。清冷月夜，思乡愁绪，色调青蓝带暖黄灯光对比。建筑比例准确，人物姿态自然，无文字无标语，9:16 竖构图，电影感，极致精细笔触。`
- **尾帧**（img-to-img, fid=0.82，机位锁死）：`同一场景的后续瞬间：诗人头已低下，垂目沉思，面部带着思乡的惆怅神色。窗外远处淡墨般的故乡山影更明显地浮现于月色中。同一卧房 interior，构图与首帧一致，无文字无标语。`
- **VideoGen 动作**：`精细工笔国风镜头，固定机位无镜头运动：诗人从仰望明月缓缓低下头、垂目陷入沉思、面露思乡惆怅；窗外故乡远山轮廓在月色中淡淡浮现；烛火摇曳。5秒，画面内运动自然流畅，无镜头旋转。`
